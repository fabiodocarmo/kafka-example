# kafka-example

Projeto desenvolvido na disciplina de Arquitetura Orientada a Eventos, demonstrando producao e consumo de mensagens com Apache Kafka.

---

## Tecnologias

- Java
- Spring Boot
- Apache Kafka
- Docker / Docker Compose

---

## Pre-requisitos

- Java 11+
- Docker e Docker Compose instalados

---

## Instalacao

```bash
git clone https://github.com/fabiodocarmo/kafka-example.git
cd kafka-example
```

---

## Como usar

```bash
docker-compose up -d
./mvnw spring-boot:run
```

O producer enviara mensagens para o topico configurado e o consumer as processara em tempo real.
